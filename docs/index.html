04 · whose brain

She'll use whichever brain you trust.

Swap them in the launcher. Bring your own API key, or run fully local. No vendor lock-in, ever.

  • 01

    Claude Code // zero config

    If you have Claude Code installed, BuddyDesk finds it automatically and uses it as the default brain. No API key, no setup, no friction.

    ▸ best for most people
  • 02

    OpenAI // compatible

    Any OpenAI-compatible endpoint. Drop in a base URL and a key.

    ▸ GPT-5.5 · custom hosts
  • 03

    DeepSeek // cheap & capable

    Surprisingly good, surprisingly cheap. A great default for budget work.

    ▸ V4 · still dirt cheap
  • 04

    Ollama // 100% offline

    Runs locally on your machine. Nothing leaves your laptop. Slower, but private.

    ▸ llama 4 · qwen 3 · gemma 3
  • 05

    NVIDIA // NIM endpoints

    For when you want a hosted model that isn't OpenAI or Anthropic.

    ▸ llama 4 · mistral · qwen 3
