# I18n API

`I18nApiV2` registers translations owned by a plugin. Declare `CAP_I18N` and query `IFACE_I18N`. `host.i18n()?` confirms table availability, but bundle registration currently uses the raw table.

## A typical use

Prepare a bundle for each language you support, such as `en-US` and `zh-CN`. Give each bundle the same keys and translated values, register them during `create`, and keep the returned IDs. Release those IDs during `shutdown`. Registering a bundle copies the strings, so the input arrays may be freed after the call returns.

`host.i18n()?` only checks that the service exists; it does not install translations. Call raw `register_bundle` to make them available. Use stable, distinct keys so one label keeps the same meaning across languages.

## Methods

Both methods take `context, token` first and return `PluginStatus`.

| Method | Remaining parameters | Result |
|---|---|---|
| `register_bundle` | `Utf8Slice` locale, `*const TranslationPairV2` pairs, count, `*mut ResourceId` | Copies and registers a bundle. |
| `release_bundle` | `ResourceId` | Unregisters the owned bundle. |

## Bundle contract

Each `TranslationPairV2` contains borrowed UTF-8 `key` and `value` slices. Supply a nonempty locale and 1–4096 pairs with nonempty, unique keys. The locale is limited to 64 bytes; a key or value is limited to 64 KiB; the sum of copied key and value bytes is limited to 1 MiB per bundle. All input slices need to remain readable only until registration returns.

The host currently allows 16 bundles and 4 MiB of bundle resource bytes per plugin. Release the ID to remove its translations, including during shutdown.

See the [raw table](https://github.com/WinIslandProject/WinIsland/blob/master/crates/winisland-plugin-api/src/abi/tables.rs) and [translation pair type](https://github.com/WinIslandProject/WinIsland/blob/master/crates/winisland-plugin-api/src/types/v2/i18n.rs).
