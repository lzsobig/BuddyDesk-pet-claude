# I18n API

`I18nApiV2` 注册由插件持有的翻译资源。声明 `CAP_I18N` 并查询 `IFACE_I18N`。`host.i18n()?` 可确认服务表可用；注册资源目前需使用原始服务表。

## 一个常见用法

为支持的语言分别准备资源，例如 `en-US` 和 `zh-CN`。两份资源使用相同的键、不同的译文；在 `create` 中注册，保存返回的 ID，在 `shutdown` 中释放。注册时宿主会复制文字，因此调用返回后可释放输入数组。

`host.i18n()?` 只是确认服务存在，不会自动安装翻译。真正注册需调用原始 `register_bundle`。键最好稳定且各不相同，避免同一个标签在不同语言中指向不同含义。

## 方法

两种方法都先接收 `context, token`，并返回 `PluginStatus`。

| 方法 | 其余参数 | 作用 |
|---|---|---|
| `register_bundle` | `Utf8Slice` 语言标记、`*const TranslationPairV2`、数量、`*mut ResourceId` | 复制并注册翻译资源。 |
| `release_bundle` | `ResourceId` | 注销所属资源。 |

## 资源约定

每个 `TranslationPairV2` 包含借用的 UTF-8 `key` 和 `value`。语言标记不得为空；提供 1–4096 个键值对，键不得为空或重复。语言标记最多 64 字节，单个键或值最多 64 KiB，单份资源中复制的键和值总计最多 1 MiB。输入切片只需保持到注册调用返回。

每个插件当前最多有 16 份翻译资源，总资源字节不超过 4 MiB。释放 ID 会移除其翻译；关闭插件前也应释放。
