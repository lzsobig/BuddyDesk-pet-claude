# 快速开始

准备好在你的 Windows 桌面上体验 WinIsland 了吗？按照以下简单的步骤来运行 WinIsland。

## 安装

1. **下载**：前往 [下载页面](/zh/download) 获取正式版或预览版安装程序。
2. **安装**：运行安装程序，并保留默认安装位置。
3. **权限**：在 Windows 管理员权限提示中选择允许，使安装程序能够注册 WinIsland 的 Windows 身份并启用通知访问等功能。

## 基础操作

- **点击**：点击灵动岛将其展开，显示工具。
- **右键（系统托盘）**：右键点击系统托盘中的灵动岛图标，访问设置、切换可见性或退出应用程序。

## 故障排除

- **没有媒体信息？**：确保你的媒体播放器支持 Windows SMTC（大多数浏览器、Spotify 和现代音乐应用都支持）。
- **国产音乐软件（网易云、酷狗等）媒体信息不正常？**：请查看[常见问题](/zh/faq)，了解各播放器对 SMTC 的支持要求。
- **模糊效果无效？**：检查你的系统是否支持硬件加速，并且是否安装了最新的显卡驱动。
