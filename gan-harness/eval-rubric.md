# Design Evaluation Rubric — Hermes Pet Win

## Scoring (1-10 per dimension)

### Design Quality (weight: 0.35)
- Does it look like a premium app, not a student project?
- Is the color palette cohesive and intentional?
- Is there proper visual hierarchy (size, weight, color, spacing)?
- Does it avoid generic template aesthetics?
- Are there micro-interactions (hover, focus, active states)?

### Originality (weight: 0.30)
- Does it have a distinctive visual identity?
- Are there creative solutions to common UI patterns?
- Does it feel fresh, not like a Bootstrap/ Tailwind template?
- Would it stand out in a screenshot comparison?
- Are animations purposeful and delightful?

### Craft (weight: 0.25)
- Is typography handled with care (hierarchy, spacing, weight)?
- Are spacing/padding values intentional, not arbitrary?
- Is color used semantically, not decoratively?
- Do transitions feel smooth and physical?
- Is there attention to edge cases (long text, empty states)?

### Functionality (weight: 0.10)
- Does the UI actually work (not just look good)?
- Are interactive elements responsive?
- Does streaming display correctly?
- Are command results shown clearly?

## Passing: 7.5/10 weighted average
## Target: 8.5/10 (design award quality)
